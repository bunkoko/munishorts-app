MuniShorts 投稿

日本の市区町村を1本約50秒で紹介する縦型ショート動画を、運営者自身の YouTube チャンネルに投稿するための個人用ツールです。

このツールがすること

  • 運営者が自分で作った動画を、運営者自身の YouTube チャンネルにアップロードします。
  • 動画のタイトル・説明（出典とクレジット）・サムネイル・公開の予約を設定し、運営者のチャンネルの再生リストに追加します。
  • YouTube Data API を使います。使うのは運営者本人の Google アカウントだけで、ほかの人のアカウントやデータは扱いません。

使う人

運営者本人だけが使います。一般の利用者に公開しているサービスではありません。

プライバシー

データの扱いはプライバシーポリシーに書いています。
