プライバシーポリシー

MuniShorts 投稿（以下「このツール」）は、運営者が自分の YouTube チャンネルに動画を投稿するための個人用ツールです。制定日：2026年10月17日

1. 扱う情報

このツールは、運営者本人が Google の画面で許可したときに、YouTube Data API を通じて次のことを行います。

  • 運営者のチャンネルへの動画のアップロードと、タイトル・説明・サムネイル・公開設定の設定
  • 運営者のチャンネルの再生リストの作成と、動画の追加
  • 運営者のチャンネルにある動画のタイトルの一覧の読み取り（同じ動画を二度投稿しないため）

運営者以外の人の Google アカウントや YouTube のデータは扱いません。

2. 使い道

上の情報は、運営者が自分で作った動画を自分のチャンネルに投稿するためだけに使います。広告、分析、販売、ほかのサービスへの提供には使いません。

3. 保存と第三者への提供

  • Google から受け取る許可の鍵（更新用トークン）は、運営者の Mac のキーチェーンにだけ保存します。
  • 投稿した動画の ID と予約の時刻は、運営者の Mac の中の記録ファイルにだけ保存します。
  • これらの情報を第三者に送ったり、提供したりすることはありません。

4. Google API サービスのポリシー

Google API から受け取った情報の使用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。また、YouTube の利用には YouTube 利用規約 と Google プライバシー ポリシー が適用されます。

5. 許可の取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」（myaccount.google.com/connections）から、いつでもこのツールへの許可を取り消せます。取り消すと、このツールは YouTube にアクセスできなくなります。

GitHub の Issue からご連絡ください。
